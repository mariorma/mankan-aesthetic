## 1. 一句话

**颜色收住，目光不躲。**

外冷内烫。表面正式、干净、克制；张力放在构图、停顿和视线里，不放在裸露和刺激里。

从数据里能看到的反复出现的词：压得住、停住、半遮、回眸、自持、站得稳、近但不挤、规矩里发烫、字比图多、留白、先写判断。

## 2. 新站名：敛色

英文副标：**Held Colour**。口号：**颜色收住，目光不躲。**

- 「敛」是收、按住、不外放。古文「敛色」是收起笑意、神情端正。
- 「色」有两层：一是颜色（品味线看的色调、刊面）；二是容色和欲望（美人线、压抑线）。
- 两个字是四条线的公约数：
  - 品味：颜色有节制，纸感，不霓虹。
  - 压抑：欲望被礼教按住，冷、正式。
  - 一人：「敛色」就是端着的一张脸，一个人自持的磁场。
  - 美人：看容色，但不俗。
- 交互上兑现站名：全站的图默认「敛」着（压暗、降饱和），看向它（鼠标停留，或手机上滚到视线中间）时颜色慢慢回来。

淘汰过的名字：屏息（好，但只覆盖张力）、静电（俏皮，太轻）、凝视（太常见）、矜色（「面有矜色」偏骄矜，贬义）。

仓库 slug 暂留 `mankan-aesthetic`，站内不再出现「慢看」。

## 4. 共同语法

**色板**（`source/src/styles/tokens.css`）

| 名 | 值 | 用在 |
|----|----|------|
| 纸 | `#ECE7DE` | 品味房间底色、日更页底色 |
| 墨 | `#121212` | 纸上的字 |
| 夜 | `#0B0D0D` | 封面、一人房间 |
| 青黑 | `#0D1716` | 压抑房间底色 |
| 冷青 | `#4F6F68` | 压抑线标签、细线 |
| 琥珀 | `#B98A44` | 唯一的暖色强调：灯、当前项、好评 |
| 骨 | `#D8D0C2` | 夜底上的字 |
| 暖暗 | `#16100C` | 美人房间底色 |
| 肤桃 | `#E6CBB3` | 美人线标签 |

不用红。旧站的漆红退役；压抑线靠冷青对琥珀，不靠血色。

**字**

- 思源宋体（Noto Serif SC，可变字重，按 unicode-range 切片自托管）：标题、判断句、刊名。
- Instrument Serif：英文、数字、日期。
- 系统黑体：正文小字、标签、按钮。

**版式**：杂志栅格，大留白，编号，竖排刊名。一页之内层次清楚：刊名 > 房间名 > 条目标题 > 一句话 > 来源。

**动效原则**：慢（不少于 600ms）、少、有因。一个房间一个主动效。`prefers-reduced-motion` 时全部退回静态；窄屏不跑 WebGL。

**图**：只用原图；每张有短来源和原帖链接，点图进原帖；页脚统一免责声明；不用 AI 图凑数；视频只嵌官方播放器（B站、YouTube、Vimeo）。

**文案**：白话、短句、先判断。不写流程话（「降级」「核活」「外链 CDN」「og 落盘」）。

## 5. 首页叙事：一天的光

首页从白天的纸滚到夜里的灯，背景色温跟着滚动走：

1. **封面**（夜）：日更池里抽一张做封面，最新一天优先。图敛着，鼠标处像台灯照亮、回色；换图时墨渗过渡。
2. **品味**（纸，白天）：按打分加权抽几条，刊面式排。
3. **压抑**（青黑，傍晚办公室）：台灯光锥压着标题，图像挂在冷墙上配展签。
4. **一人**（黑，单灯）：一次只看一个人，肖像被鼠标吸住。
5. **美人**（暖暗，台灯）：一组人像，看一张，其余退后。
6. **今日**：最新一天的全部条目，加日更入口。

所有图和字都从 `content/daily.json` 来，首页没有自己的素材。

## 6. 技巧落地

| 来源 | 用在哪 | 为什么合气质 |
|------|--------|--------------|
| 自写 WebGL2 着色器（`source/src/gl/held-stage.ts`） | 封面：图默认敛着（冷青／琥珀分离色调），鼠标处像台灯照亮、回色；没人动时灯自己慢慢游走；换图用 fbm 噪声墨渗；胶片颗粒 | 站名本身 |
| Aceternity · Lamp Section Header | 压抑房间：标题站在两道琥珀光锥里 | Hopper 的台灯 |
| Aceternity · Focus Cards | 美人房间：停在一张上，其余虚掉 | 一次只看一个人 |
| Magic UI · Lens | 品味房间头条图上的放大镜，镜片里是原色 | 学审美就是凑近看 |
| Motion Primitives · Magnetic | 一人房间：肖像被鼠标吸过去一点；再加跟手的聚光灯，只有灯下回色 | 磁场 |
| Motion Primitives · Text Effect | 房间名逐字显影 | 慢 |
| Motion Primitives · Progressive Blur | 封面底边 | 收着 |
| React Bits · Noise | 全站胶片颗粒（CSS + SVG 噪声） | 纸感、胶片 |
| React Bits · Scroll Reveal | 房间导语随滚动逐字去模糊 | 一点点看清 |
| Uiverse | 好中差单选点、叠层按钮 | 小控件要有手感 |
| Animista · text-focus-in | 刊名「敛色」、日更大标题入场 | 用 CSS，不加 JS |
| Liquid Glass（CSS 版） | 浮动导航、提示条；高光跟着鼠标走，纸底时换浅色玻璃 | 夜里的一块玻璃 |
| View Transitions API | 日更筛选、「换一批」 | 浏览器原生，不加库 |
| CSS scroll-driven animations | 房间大编号随滚动漂移、导语逐字显影（不支持时用 IntersectionObserver 补） | 浏览器原生，不加库 |
| 过渡带渐变 | 首页房间之间的色温：夜 → 纸 → 青黑 → 黑 → 暖暗 | 一天的光 |

退路：窄屏、`prefers-reduced-motion`、不支持 WebGL2 时，封面退回静态的「敛色」图（CSS 滤镜，悬停回色）；所有动效在减少动效时关掉。
